GS TYRES WEBSITE + INSTALLABLE PWA STARTER

Files:
- index.html: mobile-friendly tyre finder starter
- manifest.webmanifest: installable web app metadata
- sw.js: basic offline cache service worker
- icon.svg: app icon

IMPORTANT BEFORE PUBLIC LAUNCH:
1. In index.html, replace the demo WhatsApp number 923000000000 with the correct business WhatsApp number (digits only, country code included).
2. The records are explicitly unverified examples. Replace them with confirmed fitment information before relying on them.
3. This starter has no secure admin login, server database, payment system, live inventory sync or automatic multi-device backup.
4. Host on an HTTPS static host for PWA install support. GitHub Pages is one possible free option for a public static website; terms and features can change.
5. Open the hosted site in Chrome on Android and use the browser menu's Install app / Add to Home screen if available.
6. Test the WhatsApp button and all records before sharing the link with customers.

This is a starter, not a fully production-ready system.
